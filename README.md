## How to Use

### Option 1: Run Locally

1. Clone the repository:

```bash
git clone https://github.com/your-username/YouTube-video-Summarizer-and-Quiz-Generator.git
```

2. Navigate to the project folder:

```bash
cd YouTube-video-Summarizer-and-Quiz-Generator
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python -m streamlit run app.py
```

---

### Option 2: Use the Hosted Version

If you don't want to install anything locally, use the live web application:

**🌐 Live Demo:** https://yt-summarize-quiz.streamlit.app/
